# 《激流勇进》3v3 组队模式 PRD

| 项 | 内容 |
|---|---|
| 版本 | v0.3 |
| 日期 | 2026-11-14 |
| 状态 | P0 已完成并验收（竞技场 3v3 暂缓至 P1） |
| 适用版本 | 现有 3D 赛艇（竞速 / 道具 / 弹射 / 竞技场 / 怪物） |

---

## 1. 背景与目标

当前所有玩法都是个人名次制：玩家之间只有竞争关系，领先者一旦拉开距离，其他人缺少共同目标；道具赛也容易出现“各打各的”。

本次引入**组队赛制（最多 3v3）**：两名及以上真人分成蓝队 / 红队，以队伍名次合计决定胜负，让玩家可以分工、掩护、共享胜负。

**可观察的目标**

- 大厅可以在“个人 / 组队”之间切换，且不增加新的顶级模式入口。
- 组队模式每队最多 3 人，两队满员共 6 人，能自动均衡分队，也能由房主手动调整。
- 比赛内左侧排名**保持现有排序方式**，仅通过队伍色圆点区分队友与对手。
- 结算能明确给出“获胜队伍 + 队伍总分”，组队模式领奖台只设一个冠军台。

## 2. 范围

### P0（本次必须完成）

- 大厅赛制切换：个人 / 组队。
- 组队可玩玩法：竞速、道具、弹射。
- **竞技场 3v3 暂缓到 P1**：现有 `ArenaMode.js` 是严格 1v1，本轮组队下选择竞技场会提示「竞技场 3v3 还在开发中」。
- 怪物模式作为独立玩法单列，既不属于个人赛制，也不属于组队赛制。
- 自动均衡分队 + 房主手动换队。
- 比赛内左侧排名不分组，用队伍色圆点区分。
- 道具按 FR-06 已确认的逐项规则实现；AI 同样遵守。
- 队伍计分，三种比赛设置（单场定胜负 / 三局两胜 / 三局积分制），全部打满，不提前结束。
- 组队模式只设一个冠军领奖台。
- 开赛校验与拒绝提示；个人模式不设人数上限。
- 单人练习也能选择组队赛制（AI 补位）。
- 比赛内 + 大厅聊天都支持「队伍 / 全部」频道切换。
- 结算展示队伍命中 / 被击 / 救援数据（仅展示，不计分）。

### P1（后续迭代）

- 竞技场 3v3（本轮暂缓；现有竞技场为严格 1v1）。
- 队伍 MVP 勋章（命中 / 救援 / 最快圈最高者）。
- 队伍自定义队旗与队伍配色。
- 复活等待期观看队友视角。

### 不包含

- 观战系统、多房间匹配、排位/ELO、语音。
- 怪物模式玩法改造（只调整入口归属）。
- 新的赛道、赛艇或道具。

## 3. 核心概念

| 概念 | 定义 |
|---|---|
| 赛制（format） | `个人` 或 `组队`。决定计分与领奖台形态，不决定玩法。 |
| 玩法（mode） | 竞速 / 道具 / 弹射 / 竞技场。怪物模式为独立玩法，不受赛制影响。 |
| 队伍 | 蓝队、红队，各 1–3 人；两队满员共 6 人。 |
| 队伍色 | 蓝队 `#3aa0ff`，红队 `#ff5a5a`（设计可按视觉规范微调）。 |
| 队伍分 | 本局队内所有成员个人名次分之和；多局制下按局累加。 |

### 3.1 玩法与赛制矩阵

| 玩法 | 个人赛制 | 组队赛制 | 说明 |
|---|---|---|---|
| 竞速 | 支持 | 支持 | 计时/名次计分 |
| 道具 | 支持 | 支持 | 队友免疫攻击道具 |
| 弹射 | 支持 | 支持 | 计分规则同竞速 |
| 竞技场 | 支持（1v1） | 暂缓（P1） | 现有竞技场是严格 1v1，组队入口先拦截 |
| 怪物 | 独立玩法 | 独立玩法 | 合作打 BOSS，不显示赛制切换 |

## 4. 功能需求

### FR-01 大厅：赛制与玩法选择

**入口**：大厅右侧按钮列的「模式」按钮 → 模式抽屉。

**布局**

```
┌ 选择模式 ───────────────────────── × ┐
│ 赛制    [ 个人 ] [ 组队 3v3 ]          │
│                                        │
│ 玩法    🏁竞速  🎁道具  🚀弹射  ⚔️竞技场 │
│                                        │
│ 比赛设置 [单场定胜负][三局两胜][三局积分制]│
│                                        │
│ ───────────── 独立玩法 ─────────────   │
│ 🐉 怪物模式   合作共斗 · 不属于个人/组队 │
└────────────────────────────────────────┘
```

**规则**

| 条件 | 行为 |
|---|---|
| 打开抽屉 | 默认停留在房间当前赛制与玩法 |
| 切换赛制 | 房主可切换；客人只读，点击提示“只有房主可以更改模式” |
| 当前为怪物模式时切到组队 | 自动落到「竞速」，并提示“怪物模式不支持组队，已切换到竞速” |
| 组队下选择竞技场 | 入口保留，但提示「竞技场 3v3 还在开发中」，玩法保持不变 |
| 切回个人 | 保留当前玩法，仅恢复个人计分与个人领奖台 |
| 比赛进行中 | 所有模式/赛制按钮不可用（沿用现有规则） |

**结果与状态**

- 赛制写入房间状态，并同步给房间内所有玩家。
- 大厅信息条显示：`组队 3v3 · 🏁 地图 · 3 圈 · 三局两胜`。

### FR-02 怪物模式的独立入口

- 怪物模式从“玩法芯片”中移出，作为抽屉底部的独立卡片，带「合作共斗」标签。
- 选中怪物模式后：

  - 大厅右侧「队伍」按钮隐藏；
  - 保留上次的赛制选择，退出怪物模式后恢复（默认个人）。
- 怪物模式的开赛、关卡、难度规则完全沿用现状，本次不改。

### FR-03 大厅：队伍分配

**入口**：组队赛制且非怪物模式时，大厅右侧按钮列新增「队伍」按钮，打开队伍抽屉。

**布局**

```
┌ 队伍分配 ─────────────────────────── × ┐
│ 蓝队 2/3           红队 3/3             │
│ ● 玩家A（房主）     ● 玩家C             │
│ ● 玩家B             ● 玩家D             │
│                     ● 玩家E             │
│                                        │
│ 房主点击玩家后的「换队」即可调整          │
└────────────────────────────────────────┘
```

**规则**

| 场景 | 行为 |
|---|---|
| 玩家加入组队房间 | 自动进入人少的一队；两队人数相同进蓝队 |
| 房主换队 | 把目标玩家移到另一队；仅当另一队未满 3 人 |
| 客人操作 | 只读，不显示「换队」按钮 |
| 换队后 | 该玩家「准备」状态重置为未准备；赛艇选择保留 |
| AI 补位 | 按人数均衡自动分配到两队，每队最多 3 个位置（含 AI） |
| 比赛进行中 | 禁止换队，抽屉不可操作 |
| 本局结束回到大厅 | 队伍归属保留，不重新洗牌 |
| 玩家离开 / 被移出 | 该位置释放；剩余玩家队伍不变 |
| 重连回来 | 队伍归属保留（沿用 15 秒重连缓冲） |

**队伍名称**

- 默认「蓝队 / 红队」。
- 房主可点击队名直接编辑，长度 1–8 个字符，不能为空、不能与另一队重名。
- 修改后实时同步给房间内所有玩家，并保留到本局结束和下一局。
- 队名只影响显示，不改变队伍颜色与 A/B 归属。
- 客人只读，点击提示“只有房主可以改队名”。

**展示**

- 大厅玩家列表每行在头像与名称之间显示队伍色圆点，与比赛内规则一致。
- 大厅右侧显示 `组队 · 蓝 2 : 3 红` 的人数摘要。

### FR-04 开赛校验

开始按钮仅房主可见。点击后按以下顺序校验，命中第一条即拒绝并提示，不消耗开赛状态。

| 顺序 | 条件 | 提示文案 |
|---|---|---|
| 1 | 非房主点击 | 只有房主能开始比赛 |
| 2 | 比赛进行中且仍有活人 | 比赛正在进行中 |
| 3 | 房间内无真人 | 房间里还没有玩家 |
| 4 | 联机组队真人少于 2 人 | 组队模式至少需要 2 名真人玩家 |
| 5 | 某队 0 人 | 蓝队还没有人，先分配队伍 |
| 6 | 某队超过 3 人 | 蓝队最多 3 人，请调整队伍 |
| 7 | 两队人数差大于 1 | 两队人数差不能超过 1 人 |
| 8 | 有真人未选赛艇 | `{玩家名}` 还没选赛艇 |
| 9 | 有真人未准备（房主除外） | `{玩家名}` 还没准备 |
| 10 | 有真人在重连缓冲 | `{玩家名}` 正在重连，稍等一下 |

- 单人练习不受第 4 条限制：玩家在蓝队，AI 自动补红队。
- 单人练习的 AI 数量为 0 时，选择组队赛制会自动补 1 个 AI 对手，并提示“组队练习至少需要 1 个 AI 对手，已自动添加”。
- 校验通过后进入 3 秒倒计时（沿用现有开赛流程）。

### FR-05 比赛内左侧排名

**结论：不分组，保持现有排序逻辑。**

- 排序仍为：已完赛按完赛时间，未完赛按赛道进度，与个人模式完全一致。
- 组队模式下每行结构变为：

```
名次徽章   头像   ●   玩家名称
```

- `●` 为 8px 实心圆点，位于头像与名称之间，垂直居中：
  - 蓝队：蓝色 `#3aa0ff`；
  - 红队：红色 `#ff5a5a`。
- 按玩家实际队伍归属着色（不按“相对本地玩家的敌我”），与大厅、结算表保持一致。
- 所有参赛玩家（含自己、AI）都显示圆点；个人模式不显示圆点。
- 自己所在行仍保留现有高亮样式（描边 + 加粗）。
- 行高、徽章、头像尺寸不变，避免 6 人时挤压赛道视野。
- 顶部不新增“队伍比分”大盘；队伍比分只在结算页与领奖台出现。

**示例**

```
1st  [头像] ●  玩家A（你）   ← 蓝点
2nd  [头像] ●  玩家C          ← 红点
3rd  [头像] ●  玩家B          ← 蓝点
```

> 已确认：所有行（含自己与 AI）都显示圆点，按实际队伍着色（蓝队蓝点、红队红点）。

### FR-06 队友道具与战斗规则

**适用范围**：道具模式的全部道具；竞技场组队模式中的炮火同样适用。

**总原则**

1. 攻击型道具无法攻击队友：命中队友时穿透或无效，不产生伤害、控制、减速、击飞或屏幕特效。
2. 目标选择类道具只从对手中选目标；寻敌范围内只有队友时，按“无目标”处理。
3. “攻击前一名”改为“前一名对手”，跳过中间隔着的队友。
4. “攻击第一名”类道具：若第一名是队友，道具**直接无效**（照常消耗，但不产生任何效果）。
5. “攻击全部前方”类道具：只作用于领先的对手，队友全部跳过。
6. 防御/增益类：护盾只保护自己；天使庇佑保护全队；护盾墙只拦对手的弹道。
7. 例外道具（用户确认）：漩涡可命中队友、磁力吸盘可吸队友、逆流之门可位移到队友；剑刃风暴 / 圣域会阻挡队友。
8. AI 与真人使用同一套规则，不允许 AI 攻击队友。

**逐项规则（已全部确认）**

| 道具 | 类型 | 当前效果 | 组队模式最终行为 | 确认 |
|---|---|---|---|---|
| 氮气瓶 | 自身增益 | 瞬间加速 | 不变，只作用于自己 | 已确认 |
| 深水炸弹 | 追踪前一名 | 自动跟踪前一名，炸沉 2 秒 | 目标改为「前一名对手」，队友跳过；自己第一时打排名最高的对手 | 已确认 |
| 章鱼 | 追踪前一名 | 缠住前一名 2 秒 | 目标改为「前一名对手」 | 已确认 |
| 护盾 | 自身防御 | 3 秒免疫一切道具 | **仅保护自己**，不共享给队友 | 已确认 |
| 追踪导弹 | 锁定前一名 | 减速 + 短暂顿挫 | 目标改为「前一名对手」 | 已确认 |
| 漩涡 | 前方区域 | 前方 100 米水泡，卷入者升空 5 秒 | **队友也会被卷入**（可命中队友） | 已确认（例外） |
| 磁力吸盘 | 位移辅助 | 把自己吸向最近的领先者 | **可以吸队友**（目标包含队友） | 已确认（例外） |
| 墨鱼喷墨 | 全场范围 | 黑雾糊住所有对手 5 秒 | 只影响对手，队友无效果 | 已确认 |
| 深海瀑布 | 半径范围 | 18 米内对手被冲上天空 3 秒 | 只影响对手，队友免疫 | 已确认 |
| 天使庇佑 | 团队防御 | 3 秒无敌 + 清负面 + 小加速 | **改为保护全队**：所有存活队友（无视距离）同时获得同等效果 | 已确认 |
| 飞鱼群 | 前方群体 | 攻击所有领先于你的对手 | 只打领先的对手，领先的队友全部跳过 | 已确认 |
| 海洋之怒 | 锁定第一名 | 漩涡缠住第一名 | 若第一名是队友 → 道具无效；是对手则正常 | 已确认 |
| 减速艇 | 全场范围 | 除自己外所有对手速度减半 4 秒 | 只影响对手 | 已确认 |
| 方向转换器 | 全场范围 | 其他玩家左右反转 5 秒 | 只影响对手 | 已确认 |
| 泡泡蜻蜓 | 追踪前一名 | 把前一名关进异世界 3 秒 | 目标改为「前一名对手」 | 已确认 |
| 鱼雷齐射 | 直线弹 | 正前方三发直线鱼雷 | 命中队友时穿透，不产生效果 | 已确认 |
| 血枪狙击 | 直线贯穿 | 朝第一名方向，穿透沿途领先者 | 若第一名是队友 → 道具无效；沿途队友穿透无效果 | 已确认 |
| 圣光沙暴 | 区域锁定 | 罩住第一名 14 米，减速 + 糊眼 | 若第一名是队友 → 道具无效；队友进区不减速、不糊眼 | 已确认 |
| 逆流之门 | 位移辅助 | 瞬移到前一名身后 10 米 | **可以位移到队友**（目标包含队友） | 已确认（例外） |
| 剑刃风暴 | 近身范围 | 12 米内剑刃回旋，撞上弹开 | **队友也会被弹开/阻挡** | 已确认（例外） |
| 圣域 | 身后区域 | 进入者减速并被推开 | **队友进入也会减速并被推开** | 已确认（例外） |
| 护盾墙 | 防御 | 身后 14 米挡下所有来袭弹 | 只挡敌方弹道；队友弹道直接穿过 | 已确认 |

**目标选择的兜底**

- 找不到任何对手目标（对手已全部完赛 / 已离开）时，道具可空放，并提示“没有可攻击的目标”。
- 因“第一名是队友”而无效的道具，照常扣除并播放出手动画，但不产生命中反馈。

**队友数据统计（仅展示，不计分）**

- 命中：攻击型道具使敌方玩家进入负面状态或明显受击；区域型按实际命中人数累计。
- 被击：被敌方道具命中并进入负面状态的次数。
- 救援：天使庇佑每清除 1 名队友的负面状态计 1 次；护盾墙每挡下 1 发原本会命中队友的敌方弹道计 1 次；自己给自己清除不计。
- 展示位置：结算页的「队伍数据」区块，分别列出蓝队 / 红队的命中、被击、救援。

**道具抽取**

- 抽取权重仍按个人名次计算，不改为队伍名次，避免领先队滚雪球。

### FR-07 计分规则

#### 单局

| 项 | 规则 |
|---|---|
| 个人分 | `个人分 = 本局参赛人数 - 个人名次 + 1`（与现状一致） |
| DNF | 未完赛个人分为 0 |
| 队伍单局分 | 队内所有成员个人分之和 |
| 额外加成 | 无（取消“全员完赛 +2”） |
| 竞技场 | 本轮暂缓（P1），组队选择竞技场会提示「3v3 还在开发中」 |

**同分判定（单局必须分出胜负）**

队伍单局分相同时，队内最好名次更靠前者胜。

- 所有参赛者都有唯一名次，DNF 也按赛道进度排位，因此一定能分出胜负。
- 单局不存在平局。

**3v3 示例**

| 名次 | 1 | 2 | 3 | 4 | 5 | 6 |
|---|---|---|---|---|---|---|
| 个人分 | 6 | 5 | 4 | 3 | 2 | 1 |

蓝队拿到第 1、4、6 名 → `6 + 3 + 1 = 10`；红队拿到第 2、3、5 名 → `5 + 4 + 2 = 11`；红队本局获胜。

若两队同为 10 分，则拥有第 1 名的队伍获胜。

#### 比赛胜负（三种设置，全部打满，不提前结束）

| 设置 | 局数 | 规则 |
|---|---|---|
| 单场定胜负 | 1 局 | 该局胜者即比赛胜者 |
| 三局两胜 | 3 局 | 每局产生 1 个局胜点；**即使比分 2:0 也必须打满第 3 局**，局胜点多者获胜 |
| 三局积分制 | 3 局 | 三局队伍总积分相加，高者获胜；总积分相同则比较局胜点，再相同比较最好名次 |

- 用户确认：**任何设置下都不提前结束，必须打满设定局数**。
- 三种设置并存：保留现有「三局积分制」，新增「三局两胜」，与「单场定胜负」共三种。
- 每局必分胜负，因此三局两胜的局胜点只可能是 2:1 或 3:0，不存在平局。
- 队伍总积分与局胜点都展示在结算页；只有「三局积分制」用总积分判定胜负。

#### 竞技场 3v3（暂缓到 P1）

- 现有 `ArenaMode.js` 是严格 1v1，本轮不强行改造成 3v3。
- 组队赛制下选择竞技场时，入口保留并提示「竞技场 3v3 还在开发中」，不改变房间当前玩法。
- 后续实现时的计分口径（供 P1 参考）：每击沉 1 艘敌船队伍 +1 分，先到 10 分或时间结束比分高者胜，同分进入 60 秒突然死亡加时；禁止击沉队友。

#### 结算展示

- 单局：个人名次、个人分、队伍分、队伍胜负。
- 终局：局胜点、每局比分、队伍总分。
- 不再出现“平局”文案与平局分支。

### FR-08 领奖台（组队模式）

**组队模式只设一个冠军台。**

| 项 | 规则 |
|---|---|
| 台位 | 1 个宽台，仅获胜队伍上台 |
| 站位 | 胜队最多 3 艘船，按队内个人名次从左到右并排 |
| 台前文案 | `蓝队 获胜` + `队伍总分 18 : 15`（示例） |
| 失败队伍 | 不上台，只在结算表中展示 |
| 个人模式 | 保留现有 3 台（冠/亚/季） |
| 单人组队 | 与联机一致：只有冠军台 |
| 退出 | 沿用现有 10 秒倒计时与空格立即离开 |

**结算板**

- 单局：`名次 | 选手 | 队伍 | 赛艇 | 成绩 | 个人分`，表头下方显示两支队伍的总分与本局胜负。
- 终局：`名次 | 队伍 | 成员 | 局胜点 | 总积分`，队伍行可展开显示成员。
- 新增「队伍数据」区块：蓝队 / 红队的命中、被击、救援。
- 结算页保留个人完整排名，避免玩家看不到自己的名次。

### FR-09 单人练习的组队模式

- 单人练习与联机共用同一套赛制、计分、领奖台规则。
- 本地玩家固定为蓝队；AI 优先补入红队，红队满 3 人后剩余 AI 补蓝队。
- `AI 数量 = 0` 时自动补 1 个 AI 对手，保证有敌方目标。
- 组队练习的 AI 不得攻击同队玩家。
- 练习模式不显示“队伍分配”抽屉（名单固定为本人 + AI）。

### FR-10 断线、离开与重连

| 场景 | 行为 |
|---|---|
| 比赛中断线 | 保留席位与队伍归属 15 秒；超时移除，名次按 DNF 结算 |
| 重连回来 | 恢复原队伍、赛艇、准备状态；比赛内继续原席位 |
| 房主掉线 | 15 秒后房主顺延给下一位在线真人；队伍归属不变 |
| 队员主动退赛 | 该队继续比赛；结算按 DNF 计算 |
| 全队成员离开 | 本局照常结束；另一队按现有规则结算 |
| 所有真人离开 | 本局中断，回到大厅（沿用现状） |

### FR-11 人数上限

- 个人模式：**不设人数上限**，维持现状。
- 组队模式：每队最多 3 人，因此最多 6 人；在此基础上**不额外设置房间级上限**。
- 大厅队伍面板显示 `蓝 2/3 · 红 3/3`，不显示 `x/6`。
- 两队都满员后，第 7 名真人加入时提示“两队都已满员，等有人离开后再加入”。
- AI 不占用真人名额，但仍受每队 3 个位置限制。

### FR-12 聊天频道（比赛内 + 大厅）

**入口**：比赛中按 Enter 呼出无线电输入框；大厅按 Enter 呼出大厅聊天。

**频道**

| 频道 | 可见范围 | 说明 |
|---|---|---|
| 队伍 | 仅本方队伍 | 组队模式默认频道；大厅同样生效 |
| 全部 / 世界 | 房间内所有玩家（含对手） | 沿用现有比赛 / 大厅聊天 |

**规则**

- 组队模式下，比赛内输入框左侧与大厅频道标题旁都显示 `世界 / 队伍`（比赛内为 `全部 / 队伍`）切换按钮，点击切换。
- 个人模式不显示队伍页签，只有「全部 / 世界」。
- 默认频道：组队模式为「队伍」；个人模式为「全部 / 世界」。
- 发送后保持当前频道，不自动跳回。
- 队伍消息带频道标签；列表保留已收到的消息，切回全部频道仍能看到。
- 对手无法收到队伍频道消息，服务器只转发给同队玩家。
- 大厅聊天同样支持队伍频道：组队房间内与比赛保持一致。
- 比赛结束回到大厅后频道重置为「全部」；重连保留上次选择。
- 队伍频道历史在本局内保留，切回队伍频道仍能看到。

## 5. 共享规则

### 5.1 队伍颜色

| 队伍 | 颜色 | 圆点 | 使用位置 |
|---|---|---|---|
| 蓝队 | `#3aa0ff` | 蓝色实心圆 | 大厅玩家行、比赛排名行、队伍抽屉、结算表 |
| 红队 | `#ff5a5a` | 红色实心圆 | 同上 |

### 5.2 权限矩阵

| 操作 | 房主 | 队员 | 单人练习 |
|---|---|---|---|
| 切换赛制 / 玩法 / 地图 / 天气 | 可 | 不可 | 可 |
| 修改圈数 / 局数 / AI / 难度 | 可 | 不可 | 可 |
| 选择赛艇 | 可 | 可 | 可 |
| 准备 / 取消准备 | 不需要 | 可 | 不需要 |
| 分配队伍 / 换队 | 可 | 不可 | 不适用 |
| 编辑队名 | 可 | 不可 | 不适用 |
| 切换比赛内聊天频道 | 可 | 可 | 不适用（无队伍频道） |
| 开始比赛 / 下一局 | 可 | 不可 | 可 |
| 发起返回大厅 | 可 | 不可 | 不适用 |

### 5.3 状态流转

```
大厅（个人/组队）
  ├─ 组队：自动分队 → 选艇 → 准备 → 房主开始 → 比赛 → 结算/领奖台 → 回大厅
  ├─ 个人：选艇 → 准备 → 房主开始 → 比赛 → 结算/领奖台 → 回大厅
  └─ 怪物：独立入口 → 选关/难度 → 开始 → 关卡推进 → 结算
```

组队模式下，比赛结束回到大厅后队伍与赛制保持不变；房主可继续调整队伍再开下一局。

## 6. 与现状的差异

| 项目 | 现状 | 组队模式 |
|---|---|---|
| 大厅入口 | 5 个平级玩法 | 赛制（个人/组队）× 玩法，怪物独立 |
| 人数 | 无明确上限 | 个人不限；组队每队最多 3 人 |
| 分队 | 无 | 自动均衡 + 房主换队 + 队名可改 |

| 领奖台 | 冠/亚/季三台 | 仅冠军台（胜队） |
| 比赛聊天 | 仅全部频道 | 队伍 / 全部可切换（大厅同样支持） |
| 结算 | 个人成绩 | 个人成绩 + 队伍分 + 队伍数据 |
