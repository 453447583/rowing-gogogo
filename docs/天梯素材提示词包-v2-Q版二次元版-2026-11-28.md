## 1. 改动说明

### 1.1 v2 相对 v1 改了什么

| 项目 | v1（2026-11-27） | v2（本包） | 原因 |
|---|---|---|---|
| 图标风格 | Q 版 3D 微立体 + **赛博科技点缀**（电路纹、警示斜纹） | Q 版微立体 + **糖果高光 / 双描边 / 圆润厚实**，去掉赛博冷感 | 用户要求 QQ 三国式可爱 Q 版 |
| 描边 | 细深蓝灰 `#2A3542` 一圈 | 外深蓝灰 `#2A3542` + 内层奶白高光边（更接近 Q 版贴纸感） | Q 版识别度 |
| 图标配色 | 霓虹感强（发光青、莓红为主） | 沿用同色板，但**向 HUD 的奶白/深蓝/橙青收敛** | 贴合现有天梯 HUD |
| 音频风格 | 轻管弦 + 电子脉冲，竞技昂扬 | **可爱二次元**：钟琴 / 钢片琴 / 拨弦 / 轻电子鼓，大调、明亮、跳跃 | 用户要求彩虹岛式 BGM |
| BGM 旋律要求 | 写了 `no recognizable melody`（会抑制旋律） | 改为「**原创、有记忆点的可爱旋律**，不引用任何已有商业曲目」 | v1 写法容易生成无旋律垫底音 |
| SFX 质感 | 干净、Q 版弹性（偏电子） | 卡通拟声「啵 / 叮 / 咚 / 咻」，上扬=成功、下滑=失误 | 与可爱 BGM 同族 |
| 槽位数量 | 18 图标 + 2 BGM + 18 SFX | **不变** | 避免重复劳动，只换风格 |
| 命名 / 文件路径 | `113_st_*` / `bgm_tower_*` / `tower_*` | **不变** | 与 v1 归档和接入建议兼容 |

### 1.2 本包解决什么

1. 给天梯 18 枚图标一份「Q 版可爱」重述版提示词，配色对齐现有 HUD。
2. 给 2 首 BGM 一份「彩虹岛式可爱二次元」的完整音乐提示词（含结构、乐器、调性、循环技术要求）。
3. 给 18 条 SFX 一份同音色家族的卡通提示词，优先替换重复的 `boss_thunder_strike`。
4. 给**全部 38 条槽位**一条可直接拼接的主体描述（第 13 章），不用再自己改槽位。

### 1.3 风格来源 → 可执行特征（给 AI 看的抽象翻译）

| 参考感觉 | 落到图标 | 落到音频 |
|---|---|---|
| QQ 三国式 Q 版 | 大头小身/主体夸张圆润、双层描边、糖果色平涂 + 一颗白色高光点、无写实纹理 | — |

## 2. 风险前置页

### 2.1 本批最容易翻车的 4 件事

| 风险 | 表现 | 本包解法 |
|---|---|---|
| **把参考游戏画出来** | 出现彩虹岛角色、QQ 三国的具体道具/字体/商标，或旋律像某首现成 BGM | 提示词只写抽象特征；负面词逐字带 `no existing IP, no copied character, no cover version, no familiar tune`；出图/出音后人工比对 |

## 3. 天梯 HUD 视觉基准（新增章节，图标必须对齐）

### 3.1 代码里已确认的色值与位置

来源：`index.html:8603~8790` 的 `#tower-hud` 样式块（按 `hud_final.html` 复刻，基准 1432×776）。

| 元素 | 色值 | 图标要怎么呼应 |
|---|---|---|
| 信息卡底 | `linear-gradient(#FFFFFF → #E6F3FF)` 奶白偏蓝 | 图标主色不要太暗，避免像污点 |
| 信息卡/榜单描边 | `#17558F` 深蓝，2~2.5tu | 图标外描边用 `#2A3542`，同族但略深，能压住 |
| 楼层进度点亮 | `#5FD2FF → #1F7FD6` | 青色系作为「能量/完成」正向色 |
| 顶部阶段条 | `#FFC93C → #FF8A1E`，边框 `#A2440A` | 橙色作为「警示/倒计时」色 |
| 阶段条开启态 | `#7BE7FF → #2FA8DC`，边框 `#0E5F86` | 青色 = 通行/成功 |
| 危险态（落雷） | `#FF5B4A` | 危险红只给敌方/落雷，不要滥用 |
| 缩圈里程 | `#14B8A6` | 青绿作为缩圈专属 |
| 加冕进度 | `#FFD166 → #FF8A1E` | 金黄作为皇冠专属 |

### 3.2 图标贴上去的 4 条硬约束

1. **纯透明背景**，不要卡片、不要圆形底、不要投影——HUD 自己有卡片。
2. **主体占画布 84%**，四周留均匀透明边；HUD 里楼层图标实际显示约 32~64px，必须缩到 32px 可辨。
3. **单色块平涂 + 一颗白色高光点**，不要渐变网格、不要写实反射；叠在奶白卡上才干净。
4. **同一批视角统一**（统一四分之三视角、光源左上），摆在一起像一套。

## 9. 批量执行清单

### 9.1 顺序（别跳步）

1. **先跑 3 张图标样张**：`ST_MODE`、`ST_L01`、`ST_L10`。
   - 看：是不是 Q 版可爱（不是 emoji / 不是赛博冷感）、双层描边有没有糊、32px 是否可读、皇冠有没有「凤凰化」。
2. **锁定参数**：模型版本、种子、步数、完整提示词全文，存档到 `docs/天梯素材生成参数存档-v2.md`。
3. **再跑 P0 楼层图标**：`ST_L05`、`ST_L08`；确认危险 / 水晶两类语义不串味。
4. **再跑 P1/P2**：按槽位表批量替换；每 3 张抽检 1 张。
5. **音频先跑 2 条**：`bgm_tower_ascent`（替换程序化 BGM）和 `tower_thunder_impact`（替换重复音）。
   - BGM 先听 30 秒：是不是「可爱二次元」、有没有清晰主题、有没有像某首现成曲。
   - SFX 单听 + 与 `boss_thunder_strike` A/B 对比：必须明显不同。
6. **SFX 批量**：按「替换重复 → 补静音层 → 可选扩展」顺序。

### 9.2 生成量估算与成本提示

| 类型 | 数量 | 说明 |
|---|---:|---|
| 图标 | 18 张 | 1 模式 + 10 楼层 + 7 事件；皇冠事件复用楼层图标 |
| 图标（选中态/灰度禁用态） | +18 张 | 只有需要时才做；也可由代码换色/降透明度省掉 |
| BGM | 2 首 | 主循环 + 终局 |
| SFX | 18 条 | 先做替换重复和静音层 |
| 可选 SFX | +4 条 | 皇冠拾取/掉落、道具箱破碎、天气切换 |

> 图像/音乐生成通常按张、按条或按时长计费。**本包没有调用任何付费生成工具**，先跑 3 张 + 2 条确认风格再批量，避免返工成本乘以 38。
