## 1. 改动说明

### 1.1 本版结论

云端天梯目前**没有专属 BGM**，也**没有专属音效 key**；十层图标/HUD 基本靠 emoji 和已有图标顶着。

已确认代码事实：

- `src/main.js#audioMusicMode()`：`skytower → 'arena'`，而 `AudioEngine.js` 的 `MUSIC_SAMPLES` 没有 `arena`，所以实际走 `MUSIC.arena` 的**程序化竞技场 BGM**。
- `SkyTower*.js` 里没有 `startBossBgm()`；第 4 层雷霆龙骑士没有单独换 BOSS 曲。
- 天梯直接调用的 `audio.play()` 只有 7 处：
  - L5 落雷：`this.sfx = def.sfx || 'boss_thunder_strike'`
  - L6 刷怪：`boss_minion_spawn`
  - L7 掉圈：`boss_thunder_strike`
  - L8 护盾破 / 水晶破：`boss_thunder_strike` ×2
  - L10 加冕：`boss_thunder_strike`
  - 还有 L5 的 `this.sfx` 默认同一个音
- 即：`boss_thunder_strike` 至少被 **4 类天梯事件重复复用**，`boss_minion_spawn` 被塔防层复用；L1/L2/L9 基本没有专属事件音。
- `src/main.js:1336`：天梯模式卡图标是 emoji `🗼`。
- `src/ui/ui.js:1641~1666`：天梯 HUD/阶段条使用 `🟦 / 📋 / 🥟 / 🎁 / ⚡ / 🌩 / 🗡 / 🌀 / 💎 / 🎨 / 👑` 等 emoji。
- `src/ui/ui.js:3067`：结算标题是 `🏆 天梯登顶！ / ☁️ 本局结束`。
- `SkyTowerCrownRun.js:104~137`：皇冠先用 `TorusGeometry + ConeGeometry` 程序化占位，再替换为 `golden_crown.glb`；没有独立 2D 图标。

### 1.2 本包解决什么

1. 给天梯补 1 枚模式图标 + 10 枚楼层图标 + 7 枚事件图标。
2. 给天梯补 2 首专属 BGM（攀爬循环 / 顶层终局）。
3. 给十层补 18 条专属 SFX，优先替换重复使用的 `boss_thunder_strike`。
4. 明确哪些旧素材**应该继续复用**，不要重复生成。

| 层 | 玩法 | 当前音频 | 判定 | 建议 |

3. L1/L2/L9 三个高频交互层不能一直「静音+视觉特效」。

## 10. 验收自检清单

### 10.1 图标

- [ ] 1024×1024 PNG，带 Alpha；或按项目归档要求缩到 256×256 后仍清晰
- [ ] 主体最大边约占画布 84%，四周透明边均匀
- [ ] 背景完全透明，**没有任何投影/落地阴影**
- [ ] 光源统一来自左上方
- [ ] 描边颜色 `#2A3542`、粗细一致
- [ ] 单图不超过 3 个基础色 + 1 个强调色
- [ ] 缩到 32px 仍能一眼认出是什么
- [ ] 皇冠 / BOSS / 稀有图标没有「凤凰化」
- [ ] 没有文字、数字、水印、多余主体
- [ ] 同一批摆在一起，视角、视觉重量一致

### 10.2 音频

- [ ] WAV 母版：48kHz / 单声道 / 16bit PCM
- [ ] 峰值 -3.0 dBFS，首部无静音，尾部 20ms 淡出
- [ ] BGM：48kHz 立体声 / -6 dBFS / 可无缝循环
- [ ] 每条 SFX 只表达一个动作
- [ ] 没有人声、台词、完整旋律
- [ ] 落雷音与加冕音明显不同；护盾破与水晶碎明显不同
- [ ] 与 `boss_thunder_strike` 做 A/B 听感对比，不再是同一个音
- [ ] 在游戏内与 BGM 同场播放时不盖过关键信息
