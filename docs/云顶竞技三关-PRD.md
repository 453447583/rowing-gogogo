# 云顶竞技三关 — 细版规则稿

> 版本：v0.1 · 2026-11-24
> 状态：设计稿，未改动任何源码。
> 第一关严格按 **3 层原型** 规格写；验证通过后,再扩展到 12~20 层。
> 设计原则：**物理接触 + 环境博弈** 制造对抗,不靠互相放技能对射。

## 〇、货物选型:什么比土豆更好抢?

### 0.1 "好抢"的五个标准

| 标准 | 说明 | 土豆的表现 |
|---|---|---|
| 掉落可见 | 被撞飞时有明显轨迹、光效、声音 | 一般,土色不易看见 |
| 可分割 | 一次撞击掉一部分,不是全有全无 | 天然可分割,这点很好 |
| 价值有层次 | 普通货和高价货要一眼分得出 | 难做出层次 |
| 物理有趣 | 会滚、会弹、会飘,掉落过程有戏 | 会滚,但只滚不闪 |
| 视觉契合场景 | 云端高塔需要发光物 | 反差萌,但不绚丽 |

### 0.2 候选方案

| 货物 | 优点 | 缺点 | 适合度 |
|---|---|---|---|
| **星核水晶** | 自发光,碎裂成小块,稀有度分层清晰,视觉最搭云端场景 | 需要新建模/粒子 | ★★★★★ |
| 磁石矿 | 会互相吸附成团,抢起来有物理乐趣,掉落散开好看 | 吸附会干扰操控,规则难平衡 | ★★★★ |
| 能量电池 | 携带时可给自己加速,抢的人有实际收益 | 容易变成"谁货多谁跑得快"的滚雪球 | ★★★ |
| 火药桶 | 撞击会爆炸炸飞周围货物,戏剧性最强 | 容易变成互相引爆的混乱 | ★★★ |
| 活物(发光小兽) | 掉落后会自己跑,增加变数 | AI 行为开发量大 | ★★★ |
| 土豆 | 梗、搞笑、反差萌 | 视觉不绚丽 | ★★(保留作底层货) |

### 0.3 最终建议:分层货物

**底层保留土豆(搞笑入门),中层发光水晶,顶层星核(传说)。**

- 土豆:价值 1,轻,掉在地上很显眼,新玩家一眼看懂"要抢这个"
- 水晶:价值 3,中重,发光,掉落时碎成 2~3 块小晶片
- 星核:价值 10,重,强烈脉动光,掉落时会**弹跳两次**才落地(给下方的人反应时间)
- 三种货可以同时出现在场上,撞击时掉哪种完全看运气 → 抢高价值货的瞬间最刺激

> 这样做的好处:既有梗又有视觉层次,还不用一上来就全做新模型——原型阶段先用不同颜色/大小的同一套模型即可。

## 一、第一关:云顶天梯(3 层原型)

### 1.1 一句话玩法

三艘赛艇在云端高塔里抢货物,一层一层往上运,撞人掉货、捡货反击,把货带到塔顶入账;三分钟里谁入账总价值最高谁赢。

### 1.2 场景规格

| 项目 | L1 底层 | L2 中层 | L3 顶层 |
|---|---|---|---|
| 平台半径 | 24 m | 18 m | 12 m |
| 层高间隔 | — | 60 m | 60 m |
| 地面材质 | 石砖 + 水洼 | 云母石 + 风纹 | 水晶 + 极光反射 |
| 货物刷新 | 土豆 ×6 | 水晶 ×5 + 土豆 ×3 | 星核 ×2 + 水晶 ×4 |
| 环境效果 | 轻雾,有小水洼 | 侧风,船会被推偏 | 无风,但平台小 |
| 视觉主题 | 日落金 | 雷云紫 | 极光蓝 |

- 塔身:中央一根发光水晶柱,从 L1 贯穿到 L3 上方,顶端冲入云层
- 连接:层与层之间是**螺旋坡道**(单圈约 300°),宽 8 m,有护栏但留缺口
- 塔底:下方 30 m 是翻涌云海,能看见下面几层的轮廓
- 天空:越低越暖(日落橙金),越高越冷(深蓝 + 极光),形成"爬上去天就变了"的直观进度

### 1.3 核心循环(每轮约 35~45 秒)

```
捡货 → 上楼 → 撞人掉货 / 躲人保货 → 到 L3 顶端"入账口"结算 → 回到 L1 重新抢
```

1. **捡货**:靠近货物自动吸到船尾挂载,最多挂 6 个,超出后不能再捡
2. **上楼**:沿螺旋坡道冲上更高层;坡道有缺口,抄近道要跳跃,失败就掉下去
3. **对抗**:按 K 冲刺撞击,对手掉货;掉落的货会落到**下一层**,谁都能捡
4. **入账**:到 L3 顶端的发光入账口,船上货物自动兑换成分数
5. **重开**:入账后 2 秒传送回 L1,新一轮开始(画面要有明确的"新一圈"提示)
6. **结算**:3 分钟到,累计分数最高者胜

> 设计意图:入账后回到 L1,是为了让局内形成多次重复的高潮,而不是"爬一次就结束"。每轮都有"带多少上去"的赌注。

### 1.4 冲刺与过热(替代"按多了就输")

| 参数 | 数值 | 说明 |
|---|---|---|
| 冲刺能量 | 满 100 | HUD 上一条明显的能量条 |
| 单次消耗 | 25 | 连按 4 次见底 |
| 能量恢复 | 每秒 15 | 停止冲刺约 6.7 秒回满 |
| 过热阈值 | 连续 3 秒内按 K ≥3 次 | 不是"总次数",是"短时间密度" |
| 过热效果 | 2 秒转向失灵 + 船体发红 + 速度不掉 | 掉不掉下去取决于你当时在哪 |
| 撞击冷却 | 0.8 秒 | 防止贴脸连撞 |
| 掉货数量 | 按撞击时的速度:慢 1 个 / 中 2 个 / 快 3 个 | 高速撞击收益大,但更容易失控 |

- 关键:**过热不直接判负**。它只让你"开不动方向",如果身边没边缘,你顶多被人白撞一次
- 这样玩家敢用冲刺,对抗才激烈;技术好的人能在边缘反冲刺,把对手撞下去

### 1.5 坠落与复活

| 情况 | 后果 |
|---|---|
| 掉到下一层平台 | 丢 30% 货物(向下取整),1.5 秒无敌,可继续 |
| 掉出平台外沿(坠入云海) | 丢全部货物,2 秒后回到最近平台,播放坠落演出 |
| 掉到 L1 之下 | 回到 L1 中央,停 2 秒 |
| 被撞但没掉下去 | 不丢货,只有减速 + 屏幕震动 |

- 坠落演出:镜头跟随船下坠 0.8 秒,穿过云层,再切回重生点 —— 这段"穿云"本身就是视觉爽点

### 1.6 胜负与时长

- **单局时长**:3 分钟(原型阶段可改成 90 秒便于调试)
- **胜利条件**:累计入账价值最高
- **平局处理**:进入 30 秒加时,率先入账者胜
- **倒计时的意义**:最后 30 秒 HUD 变红,提示"最后一轮",制造冲刺抢货的高潮

### 1.7 联机与组队

| 模式 | 规则 |
|---|---|
| 单人 | 2 个 AI 对手,AI 会捡货、上楼、偶尔冲刺撞人 |
| 联机个人 | 2~3 名真人,各自计分 |
| 联机组队 | 2v2 上限,队伍共用一个"货舱"(成员捡的货自动计入公共池),但个人仍能冲刺撞对方队员 |

- **同屏方案**:原型阶段用**分屏独立镜头**(2 人左右分屏 / 3 人竖三分屏),每台镜头沿自己所在层的切线跟随
- **小地图**:显示整座塔的俯视轮廓 + 各船所在层,解决"看不到对手在哪"的问题
- 若不做分屏,退而求其次:只显示自己视角,用屏幕边缘箭头指示对手方向 + 层数

### 1.8 原型验收清单(只做 3 层,验证这 5 条)

- [ ] 相机在螺旋坡道上行进时不穿塔、不迷失方向
- [ ] 冲刺过热 + 坠落的"风险感"有趣,不是单纯惩罚
- [ ] 货物掉落 → 下层可捡的链路顺畅,不出现卡在几何体里
- [ ] 3 人联机时,货物状态同步稳定,无幽灵货物
- [ ] 单局节奏在 3 分钟内至少完成 4 轮入账

**通过后再扩展**:加层(到 12~20 层)、加风区、加每层主题、加排行榜。

## 二、第二关:星云撞球(物理竞技)

### 2.1 一句话

不比谁技能多,比谁**把一颗巨大的能量核心撞进对方球门**——靠船体、角度、冲刺时机和队友配合。

### 2.2 核心规则

| 项目 | 设计 |
|---|---|
| 场地 | 碗状浮空竞技场,中间有斜坡和两侧弹射台(把球弹起) |
| 人数 | 2v2 或 3v3 |
| 球 | 一颗直径 4 m 的发光核心,极重,单船推不动,需 2 艘以上同时顶 |
| 冲刺撞球 | 球被撞飞,速度按撞击速度计算,可以打"抛物线射门" |
| 撞人 | 冲刺撞对方船只会让它减速/打转,**不掉货、不掉血** |
| 得分 | 球整个越过对方能量门 → 得分,球回中场重新开球 |
| 时长 | 5 分钟,进球多者胜 |
| 场地变化 | 每进一球,场地向中心收缩 10%,最后变成小碗,逼出高频对抗 |

### 2.3 为什么上瘾

- **技巧上限高**:角度、力度、队友卡位、弹射台借力,每一脚都不一样
- **翻盘快**:一次远距离射门就能扳平,不会出现"领先就垃圾时间"
- **没有技能对殴**:撞击不是为了打人,是为了改变球的位置,对抗是"体育式"的
- **耐玩**:地图小,物理变化多,每次开球的球速/角度都不同

### 2.4 与第一关的差异

第一关是"向上爬"的垂直进度;第二关是**平面的物理对抗**。节奏更快,更适合短局热身或观战。

## 三、第三关:崩塌浮岛(生存 + 贪心博弈)

### 3.1 一句话

脚下的平台从外圈开始一块块碎掉,你要在转移的同时抢高价值货物送回中央塔——**越危险的地方货越值钱**。

### 3.2 核心规则

| 项目 | 设计 |
|---|---|
| 场地 | 中央中央塔 + 三层环形浮岛(约 24 块),外圈开始逐块崩塌 |
| 崩塌节奏 | 每 20 秒崩 2~3 块,碎裂前 3 秒有裂纹发光预警 |
| 货物分布 | 越靠外圈价值越高(外圈星核,中圈水晶,内圈土豆) |
| 目标 | 把货物送回中央塔入账,累计分数最高者胜 |
| 风险 | 崩塌时站在上面 = 坠落出局(或掉到下一层丢一半货) |
| 中央塔 | 有一部慢速升降梯,可以上到安全的小平台,但那里没有货 |
| 时长 | 4 分钟,或场上只剩一人时提前结束 |
| 对抗 | 冲刺撞人可以让人打滑、掉货,也可以把人**撞进即将碎裂的格子** |

### 3.3 为什么上瘾

- **缩圈压迫感**:空间越来越小,冲突密度自然上升,不用刻意设计"强制打架"
- **贪心博弈**:外圈货最值钱但最快碎,走过去值不值?这是每局都要做的决策
- **第三方坐收**:别人在外圈互撞时,你在内圈稳稳入账 —— 心理战成分重
- **耐玩**:崩塌顺序随机、货物刷新随机,每局地形都不一样

### 3.4 与第一、二关的差异

第一关拼"运货路线",第二关拼"物理配合",第三关拼**"风险判断 + 生存"**。三种不同的爽点。

## 四、三关节奏对比

| | 第一关 云顶天梯 | 第二关 星云撞球 | 第三关 崩塌浮岛 |
|---|---|---|---|
| 核心爽点 | 爬升的进度感 + 抢货 | 一脚定胜负的射门 | 缩圈压迫 + 贪心博弈 |
| 对抗方式 | 撞人掉货 | 撞球不入人 | 借崩塌地形坑人 |
| 单局时长 | 3 分钟 | 5 分钟 | 4 分钟 |
| 视角 | 垂直分层 + 分屏 | 平面全景 | 俯视 + 局部特写 |
| 适合场景 | 主玩法、排位 | 快速对局、观战 | 大赛、淘汰赛 |

## 五、落地建议(下一步)

1. **先做第一关 3 层原型**,只验 1.8 的 5 条,别铺 20 层
2. 原型阶段货物用同一套模型改颜色/大小,省建模
3. 相机方案先做分屏,再评估要不要做共享镜头
4. 联机只同步"捡/掉/入账"事件,货物落地动画各端自己算
5. 第二、三关等第一关验证后再排期,不要三条线一起开
