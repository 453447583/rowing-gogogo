# 赛艇游戏图标库 · 完整对照表（89 枚）

一套 89 个游戏图标，1024×1024 透明 PNG，Q 版 3D 微立体 + 赛博科技点缀。
风格统一：浅底设计、圆润造型、单一光源、细深蓝灰描边，抠图已去背景与投影。

本包提供的是 **22 个道具之外的全部 67 枚**，按类别分在 9 个子目录里。

## 四、四条使用注意

1. **显示尺寸给 40~72px**，别按 1024 显示。浏览器自动降采样，边缘更顺；直接 1024 会糊还吃显存。
2. **浅色格子加一圈内描边**：`box-shadow: inset 0 0 0 6px rgba(10,20,35,.28)`，否则浅图标会融进浅底。
3. **难度三档靠图标本身区分**（白剑 → 火剑 → 骷髅），不用在图上写“普通/精英/噩梦”，避免生图写错字。
4. **BOSS 主题图标**（86~89）是场景缩略图，适合做「关卡选择卡」背景，别放在小尺寸按钮里。

## 五、这套图标的技术规格

| 项目 | 参数 |
|---|---|
| 尺寸 | 1024×1024 PNG，带 Alpha |
| 图标占比 | 最大边约占画布 84%（四周留 8% 透明边） |
| 背景 | 已完全透明，无投影、无底色 |
| 配色 | 天蓝 #4FC3F7 / 深海蓝 #2A6FBA / 亮橙 #FF8A3D / 柠檬黄 #FFD25A / 莓红 #FF5A7A / 紫 #9B7BD8 / 发光青 #35E6E0 |
| 风格 | Q 版卡通 + 3D 微立体 + 赛博科技点缀（细电路纹、警示斜纹、发光缝） |
| 统一项 | 视角、光源方向、描边粗细、视觉重量 |
